# AIVFX AI SYSTEMS — дизайн-направление

Дистилляция из 4 референсов (Factory, Atlantic.vc, Apple, Arsenijs Fabrica)
под наш pivot: premium B2B, тёмный + deep purple, «инструмент, а не маркетинг».

## Палитра (уже в :root, index.css)

- Канвас: `--bg #08070d` → поверхности ступенями `--bg-2 #0e0c16` → `--bg-3 #141021`
- Текст: `--fg #f2f0f8`, вторичный `--fg-2`, muted `--muted`
- Акцент: `--accent #8f6bff` (neon purple) — ТОЛЬКО для: тонированных слов
  в заголовках, статусов/лайв-индикаторов, ключевых линков, узлов схемы.
  НЕ для крупных заливок и фонов карточек.
- Одна тёплая нота отсутствует — система строго холодная. Зелёно-мятный
  `#5fd4a8` разрешён только как статус «ok» в лентах событий.

## Типографика (принципы из Factory/Atlantic/Apple)

- Авторитет = размер + плотный трекинг, НЕ жирность.
  Display: вес 500–600 максимум (не 800), letter-spacing −0.03…−0.04em, lh ≈ 1.
- Заголовки секций — слева, не по центру.
- Приём «тонированное слово»: одно-два слова заголовка в `--accent`
  (наш класс `.it`), остальное — нейтральный fg.
- Mono (JetBrains Mono) = «голос инструмента»: eyebrow/кикеры/лейблы/чипы,
  UPPERCASE, 10–12px, трекинг широкий 0.12–0.16em. Видишь mono — значит
  смотришь на систему, а не на маркетинг.
- Гигантские цифры статистики: вес 200–300, очень плотный трекинг (Refero).

## Поверхности и глубина

- БЕЗ теней и блюров. Глубина = ступени поверхностей (#08070d → #0e0c16 →
  #141021) + 1px бордеры `--line`/`--line-2`.
- Glow — дозированно: только hero-визуал и импульс схемы системы. Карточки — плоские.
- Фирменный ход Factory: ОДНА светлая карточка (#eeeceff5-подобная) на тёмном
  канвасе — используется единожды, для конверсионного CTA-блока (контакты).
  Больше нигде светлых заливок нет.
- Wireframe-рамки Atlantic: тонкая рамка + маленькие точки по углам —
  для «окон системы» (hero-визуал, SYSTEM LOG, схема).

## Motion (Factory: «CLI-инструмент, не маркетинг»)

- Транзишены: 0.15–0.2s, cubic-bezier(0.4, 0, 0.2, 1). Цвет/фон/бордер
  переключаются вместе — как один щелчок тумблера.
- Разрешённые именованные анимации: медленный marquee (тикер), каскадный
  вход строк «живой ленты», импульс по рельсу схемы. Всё остальное — статично.
- Никакого parallax, spring-физики, scroll-driven эффектов.
- prefers-reduced-motion отключает всё.

## Запреты

- Тени/glow на карточках и кнопках; больше одного акцентного цвета;
  жирность 700+ в display; эмодзи в UI; стоковые AI-образы (мозги, роботы,
  шары); градиентные заливки текста и кнопок; скругления больше --r-lg.

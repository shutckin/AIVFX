# AIVFX Robot Teaser Keyframes — Round 07 Tactile / Surreal

Date: 2026-05-29

## Direction

This round follows the new tactile references: physical marks, embossing, imprints, editorial objects, and small surreal everyday accidents.

It is less lifestyle-candid than Round 06 and more like premium visual identity studies:

- debossed concrete
- cap poster
- ice cream splat
- sand imprint
- black leather deboss
- dusty glass finger drawing
- wet pavement reflection
- white ceramic deboss
- torn red poster
- metal token in hand
- dust footprint

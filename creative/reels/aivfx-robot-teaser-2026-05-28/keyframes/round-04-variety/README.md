# AIVFX Robot Teaser Keyframes — Round 04 Variety

Date: 2026-05-28

## Direction

This round moves away from the original reference structure. Instead of repeating the same "logo hidden in material" trick, it shows varied real AIVFX-world moments:

- studio door decal
- laptop sticker
- editing monitor detail
- white equipment case
- clapperboard corner stamp
- cinema lens reflection
- storyboard notebook doodle
- hoodie seam tag
- access card
- acrylic lightbox
- exterior studio poster
- phone card

The mark has mixed scale now: tiny in some frames, medium in others, but never huge or centered as a hero logo.

# Внедрение Битрикс24 для заявок с сайта: пошаговая инструкция

Живой прогон на портале студии, сентябрь 2026. Цель: повторять у клиента
по шагам, а не изобретать на месте.

## 0. Что нужно знать до старта

- Битрикс24 облачный, зона ru. REST API и вебхуки работают **только с
  подпиской «BitrixGPT + Маркетплейс»**, а она продаётся только на платных
  тарифах. На бесплатном тарифе вебхук не создать. У нового портала есть
  15 дней демо старшего тарифа плюс 15 дней пробной подписки Маркетплейса.
- Значит, у клиента должны быть: платный тариф (минимум «Базовый») плюс
  подписка Маркетплейс. Без этого связка «сайт → CRM» невозможна, только
  ручной ввод или встроенные CRM-формы Битрикса.
- Роботы и триггеры на бесплатном тарифе: не больше 5. Воронка одна.
  Открытая линия одна.

## 1. Входящий вебхук (10 минут)

1. Портал → «Разработчикам» (`/devops/`) → карточка «Другое» → «Входящий вебхук».
2. Если появляется окно «Доступно в единой подписке BitrixGPT +
   Маркетплейс», нажать «Включить бесплатно на 15 дней» (пробный период)
   или купить подписку. Без этого дальше не пустит.
3. Откроется страница вебхука с адресом вида
   `https://портал.bitrix24.ru/rest/1/КЛЮЧ/`. Этот адрес и есть секрет:
   кто его знает, тот пишет в CRM от имени пользователя.
4. Внизу «Настройка прав» → «+ выбрать». Список не листается колесом:
   набрать в поле `crm`, выбрать «CRM (crm)». Больше прав не давать.
5. «Сохранить». Вебхук появится в списке «Интеграции» с доступом CRM.

## 2. Функция заявок (сторона сайта)

Код в `aivfx-lead-api/api/lead.js`, функция `sendBitrix`:

- ищет контакт по телефону, потом по e-mail (`crm.contact.list`);
- если нет, создаёт (`crm.contact.add`) с телефоном, почтой, компанией;
- создаёт сделку (`crm.deal.add`) с заголовком «Имя: направление
  (aivfx.ru)», в комментарии текст заявки, бюджет, канал связи и источник
  перехода.

Работает и в «простой» CRM без лидов, и в классической. Адрес вебхука
берётся из переменной `BITRIX_WEBHOOK`; пока она не задана, шаг молча
пропускается, заявка всё равно уходит в Telegram и Notion.

Переменную задаёт владелец портала сам, в терминале, в папке функции:

```bash
vercel env add BITRIX_WEBHOOK production
```

и вставляет адрес вебхука по запросу. Затем выкат: `vercel --prod --yes`.

## 3. Проверка

Отправить с сайта заявку с пометкой «тест». Ожидаемо: сообщение в
Telegram, строка в Notion, в Битриксе новый контакт и сделка в первой
стадии воронки. Тестовую сделку потом удалить или пометить как спам.

**Прогон 06.09.2026:** тестовая заявка с сайта за одну секунду дала
контакт «Тест Битрикс» и сделку «Тест Битрикс: AI-системы (aivfx.ru)»
в стадии «Новая» общей воронки. Telegram и Notion получили её же.

## 4. Роботы (15 минут)

Канбан сделок → кнопка «Роботы» (`/crm/deal/automation/0/`).

- В демо-портале воронка приходит с 14 шаблонными роботами
  (уведомления, «контроль руководителю», звонки). Для одного человека
  они бессмысленны, а на бесплатном тарифе работают только 5. Удалить
  все крестиком на карточке, подтверждения нет, потом «Сохранить» внизу.
- Добавить на стадию «Новая» через «+» под названием стадии:
  1. «Информирование сотрудников → Добавить уведомление», когда: сразу.
     Текст: «Новая заявка с сайта aivfx.ru. Открой сделку, прочитай
     задачу клиента и свяжись с ним в течение часа удобным ему способом».
     Отправитель: выбрать себя, без отправителя робот не сохранится.
  2. «Контроль сотрудников → Поставить задачу», когда: сразу.
     Название «Связаться с клиентом по заявке с сайта», описание с
     порядком действий. Срок можно не ставить: напоминание ниже
     сработает само.
  3. «Добавить уведомление», когда: через 1 день. Робот отложенный и
     живёт только пока сделка стоит в стадии: если сделку передвинули,
     напоминание не придёт. Текст: «Заявка висит в „Новых“ уже сутки…».
- Внизу страницы «Сохранить»: без этого роботы не применяются.
- Проверка 06.09.2026: вторая тестовая заявка с сайта через 10 секунд
  дала уведомление и задачу «Связаться с клиентом по заявке с сайта»
  в «Моих задачах». Роботы срабатывают только на сделки, попавшие в
  стадию после сохранения, на уже лежащие там не действуют.
- Итого 3 робота из 5 доступных на бесплатном тарифе. Роботы «написать
  клиенту» (e-mail, мессенджер) требуют подключённой почты или открытой
  линии, см. раздел 6.

## 5. Стадии воронки (5 минут)

Канбан сделок: навести на заголовок стадии, нажать карандаш, ввести
название, Enter. Стандартные «Подготовка документов / Счёт на предоплату
/ Финальный счёт» заточены под товарные продажи. Для студии:

1. Новая заявка (сюда падают заявки с сайта, здесь работают роботы)
2. Связались (первый контакт состоялся, ждём брифа)
3. Бриф и смета (бриф получен, смета отправлена)
4. В работе (предоплата получена, делаем)
5. Сдача и оплата (сдали, ждём остаток)
6. Сделка успешна / провалена (системные стадии, не трогаем)

Осторожно: клик мимо карандаша открывает карточку сделки, а Cmd+A
вне поля ввода выделяет всю страницу. Сначала навести, дождаться
карандаша, потом кликать.

## 6. Открытая линия с Telegram (20 минут)

Нужен бот в Telegram. **Проверить старого бота перед подключением:**
если описание бота само меняется на спам или в нём чужие ссылки, токен
утёк, бот скомпрометирован. Такой бот удалить в @BotFather и завести
новый. Токен вводит владелец сам: Контакт-центр → Telegram → «Подключить»
→ поле «Токен доступа». Там же текст приветствия.

После подключения: Контакт-центр → «Ещё» → «Список открытых линий»
(`/contact_center/openlines/list/`) → «Редактировать». Открывать
настройки лучше по прямой ссылке `/contact_center/lines_edit/?ID=N`:
всплывающая панель со страницы коннектора съезжает, и клики попадают
не туда.

- Очередь: «Если клиент не найден в CRM» → «Автоматически создавать
  сделку». По умолчанию стоит «создать лид», а сайт заводит сделки,
  лучше не смешивать.
- Автоматические действия: приветствие один раз при первом обращении;
  «Время до отметки как неотвеченного» 5 минут; «Действие, если
  операторы не ответили» → «Отправить текст» (в поле стоит шаблон
  Битрикса, заменить своим); прощание при закрытии.
- Рабочее время: выключено, чтобы линия отвечала всегда; текст для
  нерабочего времени заменён на свой на случай включения.
- Enter в любом поле формы отправляет всю форму: значения сохраняются,
  но открытые списки закрываются. Для выпадающих списков надёжнее
  выбирать через инструмент формы, а не мышью.

Проверка: написать боту с личного аккаунта, должны прийти приветствие,
диалог в «Список диалогов» и новая сделка с контактом в канбане.

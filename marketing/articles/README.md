# Статьи для внешних площадок (backlinks)

Статьи для публикации на сторонних площадках, чтобы получить качественные
обратные ссылки на aivfx.ru (backlinks). Чем больше авторитетных сайтов
ссылаются на тебя, тем выше сайт ранжируется в Google и Яндексе.

**С 2026-08-07 это не разовая акция, а еженедельный цикл** — см. `rotation-log.md`
для истории и статусов. Автоматическая задача `aivfx-weekly-backlink-article`
(в /Users/art/.claude/scheduled-tasks/) каждый понедельник готовит новый
черновик и пишет Артёму уведомление. Публикация — только вручную, после его "ок".

## Как опубликовать (пошагово)

1. Зайди на площадку (vc.ru и Дзен — уже авторизованы).
2. Нажми «Написать публикацию» / «Написать статью».
3. Скопируй текст из `.md` файла (без верхнего блока с пометками `>` — он только
   для тебя). ⚠️ Ни vc.ru, ни Дзен НЕ конвертируют `**жирный**`, нумерованные и
   `- ` списки при наборе текста — только `## ` → заголовок работает на обеих.
   Жирный/списки проще оставлять как связную прозу, ссылки добавлять вручную
   через тулбар выделения (выделить текст → иконка 🔗 → вставить URL → Enter).
4. Добавь 2–3 картинки (можно кадры из портфолио) — статьи с визуалом читают лучше.
5. Ссылки на aivfx.ru уже встроены в текст в конце — **не убирай их**, это и есть
   цель публикации.
6. Опубликуй.

## Важно про ссылки

- Статьи содержат естественные ссылки на `aivfx.ru` и `aivfx.ru/blog/` в концовке.
- Не вставляй ссылки в каждый абзац — площадки и поисковики считают это спамом.
- Одна-две ссылки в контексте полезного текста — идеально.

## Тон

vc.ru и Дзен минусуют откровенную рекламу. Поэтому статьи на 90% — реальная
польза (разбор процесса, цифры, грабли) и только на 10% — про студию. Это
правильная пропорция: так статья наберёт просмотры и ссылка сработает.
